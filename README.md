# planner

Планировка жилого дома 8,0 × 13,5 м на участке 19 × 35 м.
Цоколь + первый этаж с гаражом + второй этаж.

## Идея

Геометрия живёт в одном файле `data/house.json` — в миллиметрах, целыми числами.
Всё остальное из него выводится: чертежи, экспликации, площади, проверки.
Площади нигде не хранятся, а считаются — подписать одно, а нарисовать другое невозможно.

## Команды

```
npm run check   # прогон правил: нормы и эргономика
npm run build   # out/*.svg
npm run shot    # out/*.png  (нужен @resvg/resvg-js, ставится через npm i)
npm run site    # site/ — статическая страница с чертежами, экспликациями и заданием
npm run all
```

`check` возвращает ненулевой код при любом нарушении — годится для CI и для pre-commit.

## Публикация

`.github/workflows/pages.yml` на каждый push прогоняет `check`, собирает `site/`
и выкладывает на GitHub Pages. Правила стоят воротами: с нарушением геометрии
страница не обновится.

Один шаг делается руками, токен workflow на это прав не имеет:
Settings → Pages → Source → **GitHub Actions**. После этого достаточно
перезапустить последний workflow — деплой пройдёт.

Адреса и данные владельца в репозитории нет и быть не должно: он публичный,
и с него собирается сайт. Площадка описана только числами — климат, сейсмика,
габарит участка, ориентация.

## Структура

```
data/house.json   геометрия: оболочка, уровни, стены, проёмы, окна, помещения, мебель
data/brief.json   задание: что зафиксировано, ограничения площадки
src/render.mjs    отрисовка плана в SVG
src/rules.mjs     правила: связность, зоны подхода, проходы, окна, лестница, стояки
bin/check.mjs     прогон правил
bin/build.mjs     сборка SVG
bin/shot.mjs      растеризация в PNG
bin/site.mjs      сборка страницы для Pages
```

## Система координат

X — поперёк дома (0 … 8000), Y — вдоль, от улицы вглубь участка (0 … 13500).
Верх плана — юго-запад, там улица и ворота. Азимут фронта 235°.
Низ плана — северо-восток, глубина участка. Правая сторона — юго-восток, солнечная.
